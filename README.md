# SketchWise v1.0 — Daily Sketch Teacher

A tiny drawing habit app.

## What it does

- One sketch prompt per day
- Built-in simple reference sketches
- Step-by-step drawing breakdown
- Teacher notes
- Practice timer
- Prompt library
- Category filters
- Favourites
- Mark done
- Mobile-first PWA-style app

## Upload

Upload these files to your repo root:

- index.html
- app-v1-0.js
- style-v1-0.css
- app.js
- style.css
- icon.svg
- manifest.json
- service-worker.js
- README.md

## Note

This is intentionally not a complex art course. It is a small habit builder:
look, draw, repeat.
